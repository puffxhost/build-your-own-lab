# Build Your Own Lab

Learn how software works by building small versions of it yourself.

Pick one project, follow a guide, and add features as you learn. These are practice projects, not production replacements.

## New here?

Try a **command-line tool**, a **JSON reader**, or a **small 2D game**. Each can start small and grow at your own pace.

## Project ideas

### Programming and tools

- **Command-line tool** — Make a program that takes an input and prints a useful result. [Rust CLI guide](https://rust-cli.github.io/book/)
- **JSON reader** — Read JSON text and show its values. [JSON format guide](https://www.rfc-editor.org/rfc/rfc8259)
- **Programming language** — Make a tiny language that can calculate expressions. [Crafting Interpreters](https://craftinginterpreters.com/)
- **Git basics** — Save file versions and show what changed. [Git book](https://git-scm.com/book/en/v2)
- **Text editor** — Make a simple editor that can open and save a file. [Kilo editor tutorial](https://viewsourcecode.org/snaptoken/kilo/)

### Web and networking

- **Web server** — Receive a web request and send back a page. [HTTP guide](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview)
- **DNS lookup tool** — Ask a DNS server for the address behind a domain. [DNS format](https://www.rfc-editor.org/rfc/rfc1035)
- **WebSocket chat** — Send messages between connected users. [WebSocket standard](https://www.rfc-editor.org/rfc/rfc6455)
- **Reverse proxy** — Receive a request and pass it to another server. [Proxy guide](https://developer.mozilla.org/en-US/docs/Web/HTTP/Proxy_servers_and_tunneling)
- **BitTorrent client** — Find peers and download a small file in pieces. [Protocol basics](https://www.bittorrent.org/beps/bep_0003.html)

### Data and distributed systems

- **Key-value database** — Save and retrieve values using a key. [SQLite architecture](https://www.sqlite.org/arch.html)
- **SQL query tool** — Run simple queries on a small table. [How SQLite works](https://www.sqlite.org/howitworks.html)
- **Search tool** — Index a group of notes and find matching results. [Information retrieval book](https://nlp.stanford.edu/IR-book/)
- **Message queue** — Put jobs in a queue and let a worker process them. [RabbitMQ tutorials](https://www.rabbitmq.com/tutorials)
- **Raft demo** — Show how a group of computers can agree on a shared log. [Raft guide and visualizer](https://raft.github.io/)

### AI and machine learning

- **Automatic differentiation** — Calculate how a small change in input affects an output. [micrograd example](https://github.com/karpathy/micrograd)
- **Neural network** — Train a tiny model and inspect how it learns. [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html)
- **Text tokenizer** — Split text into the pieces a language model reads. [GPT-2 tokenizer example](https://github.com/openai/gpt-2/blob/master/src/encoder.py)
- **Document search with AI** — Find useful passages before answering a question. [RAG from Scratch](https://github.com/langchain-ai/rag-from-scratch)

### Graphics and computer systems

- **Ray tracer** — Draw simple 3D shapes by tracing light rays. [Ray Tracing in One Weekend](https://raytracing.github.io/books/RayTracingInOneWeekend.html)
- **2D game** — Build a game loop, add controls, and detect collisions. [MDN Breakout tutorial](https://developer.mozilla.org/en-US/docs/Games/Tutorials/2D_breakout_game_Phaser)
- **CHIP-8 emulator** — Run simple programs in a tiny virtual machine. [Emulator guide](https://tobiasvl.github.io/blog/write-a-chip-8-emulator/)
- **Memory allocator** — See how a program can reserve and reuse memory. [Allocator notes](https://sourceware.org/glibc/wiki/MallocInternals)
- **Tiny operating system** — Start a small kernel and learn how it talks to hardware. [OSDev Wiki](https://wiki.osdev.org/Main_Page)

## How to use a guide

1. Pick one small feature to build first.
2. Follow the guide and make that feature work.
3. Try changing it, then write down what you learned.

## Add a project

Have a useful beginner-friendly guide? [Open an issue](https://github.com/puffxhost/build-your-own-lab/issues) or send a pull request. Include a short description and a direct link. Please write descriptions in your own words.
