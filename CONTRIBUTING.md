# Contributing

Thanks for helping improve Build Your Own Lab.

## Add a resource

1. Choose the closest existing category, or explain why a new one is useful.
2. Link directly to the tutorial, specification, or project documentation.
3. Include a concise description of what someone will build or learn.
4. Prefer resources with a clear progression, working examples, and no unnecessary paywall.
5. Verify the destination and avoid duplicates before opening a pull request.

## Keep it useful

- Do not paste third-party tutorial text, diagrams, or code here.
- Mention language, prerequisites, difficulty, or maintenance status when that information is clear.
- Keep descriptions neutral and factual.
- Respect each source's license and terms.

By submitting a contribution, you agree that your original contribution to this repository is released under the MIT License.
